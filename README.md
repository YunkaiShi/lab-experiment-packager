# Lab Experiment Packager

端到端实验任务助手。从实验报告模板出发，分析报告任务要求、规划实现方案、撰写代码、运行实验、生成图表、按模板位置精准填写报告、检查格式保护、分离纯净代码，最终整理成规范命名的提交文件夹。

适用于机器学习、遗传算法、数据分析等课程实验。

---

## 安装

### 通过 Git 克隆

```bash
git clone https://github.com/YOUR_USERNAME/lab-experiment-packager.git ~/.claude/skills/lab-experiment-packager
```

### 手动安装

1. 下载本项目的 ZIP 文件或克隆到本地
2. 将 `lab-experiment-packager` 文件夹复制到 Claude Code 的 skills 目录：
   - **macOS/Linux**: `~/.claude/skills/`
   - **Windows**: `%USERPROFILE%\.claude\skills\`

3. 确保文件夹结构如下：
   ```
   ~/.claude/skills/lab-experiment-packager/
   ├── SKILL.md       # 技能定义文件
   ├── README.md      # 本说明文档
   └── LICENSE        # 许可证
   ```

### 验证安装

重启 Claude Code 后，在对话中输入：

```
/lab-experiment-packager
```

如果安装成功，该技能将被激活。

## 核心工作流

本 Skill 遵循 **7 步工作流**：

```
Step 1: 分析报告中的任务
    ↓
Step 2: 任务梳理结果展示 → 用户确认
    ↓
Step 3: 规划任务
    ↓
Step 4: 完成对应的工作（写代码、运行、出图）
    ↓
Step 5: 精准填写报告（代码 + 结果/图像，看情况）
    ↓
Step 6: 检查格式 + 代码净化
    ↓
Step 7: 创建教学文档 + 整理归档
```

### 关键原则

1. **模板即需求**：报告模板中明确列出了实验目的、步骤、需要截图的位置、需要填写的数据。分析模板 = 分析任务。
2. **任务确认制**：分析出的任务清单必须展示给用户确认，确认无误后才进入执行阶段。
3. **精准插入**：图像和结果必须插入到模板中"对应的位置"，优先直接修改原有段落（替换占位符）。
4. **看情况输出结果**：不是所有步骤都需要贴运行结果。判断标准：
   - **只需代码**：运行结果无信息量（如"加载成功"、"训练完成"）→ 只贴代码
   - **代码 + 关键结果**：运行结果有数值意义（如准确率 98.33%、最优 k=1）→ 贴代码 + 一行结果
   - **代码 + 详细结果**：运行结果本身就是分析对象（如混淆矩阵数值、错误样本索引）→ 贴代码 + 详细输出
5. **格式保护**：填写报告时不能破坏模板的原有字体、段落、页边距等格式。
6. **代码分两份**：最终提交的 `.py` 文件里绝对不能有 `from docx import Document`。
7. **教学文档**：全部工作完成后，创建 Markdown 格式的原理讲解文档。

## 适用场景

- **机器学习实验**：KNN、SVM、决策树、神经网络等分类/回归任务
- **遗传算法实验**：二进制编码、轮盘赌选择、交叉变异、适应度曲线
- **数据分析实验**：数据可视化、统计检验、特征工程
- **任何需要**：代码 + 图像 + 报告 + 教学文档 的课程实验
